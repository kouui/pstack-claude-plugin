# Slack 对话

## 如何搜索

Slack MCP 工具各不相同。先检查可用的是哪个 Slack MCP，并查看其工具 schema。它可能需要 `mcp_auth`。如果认证失败，请停止并报告缺口。

1. **限定作者的搜索。** 查找 PR 作者在 PR 合并日期前后的消息。这能大幅缩小范围，且常常能找到关键信息。
3. **PR URL 搜索。** Slack 在 PR 被 review 或讨论时常会链接该 PR。搜索 PR URL（或仅搜索 `/pull/<number>`）。
4. **错误字符串搜索。** 如果代码处理某个特定错误，就搜索该错误字符串。事故讨论串中常会出现这些内容。

## 常见误区

- **频道考古的限制。** 很早之前的消息可能因保留策略已被删除。如果某个日期之前什么都找不到，请记录该保留期限的截断点。
- **无法搜索的私信。** 许多决定是在无法搜索的私信中做出的。你会漏掉这些内容。这是已知的局限。
- **把随口玩笑当作"决定"。** Slack 语气随意。"哈哈直接做就行"不是决定，即使它出现在提交之前。应寻找经过考虑的讨论。
- **单条消息的语境丢失。** 脱离讨论串，单条消息的含义往往与语境中不同。务必获取完整讨论串。
- **认证失败。** 如果 MCP 未通过认证，就停止。不要编造发现结果。请报告 Slack 无法搜索。
