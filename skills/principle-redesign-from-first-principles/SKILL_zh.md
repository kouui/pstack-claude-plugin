# 从第一性原理重新设计

集成变更时，不要把它硬接到现有设计上。请像这个需求从一开始就是基础假设那样重新设计。

- 阅读所有受影响的文件，理解当前设计
- 自问："如果从零开始编写，并且包含这个新需求，我们会构建什么？"
- 将变更传播到每一处引用：类型、文档、示例、理由说明章节
- 思考整体重新设计，然后分增量交付

这是在将变更集成到现有设计中时，保留选择余地的方法。
