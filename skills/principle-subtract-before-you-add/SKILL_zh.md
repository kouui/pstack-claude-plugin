# 先减后加

演进系统时，先移除复杂度，再进行构建。默认采用减法。

让简化成为持续的投入。在与原来相同或更小的表面积上，让设计比你发现时更简单、能力更强。

- 先移除，后构建
- 先削减，再打磨（在投入质量之前先达到最小化）
- 为观察到的使用方式设计，而不是为假想的边界情况设计
- 除规范要求之外，不做推测性的校验器、解析器或守卫
- 简化提示词（删除冗余指令、过多的模板）
- 当某个参考资料没有新内容时，删除它，而不是留下桩文件
