# 绝不因人类而阻塞

人类是异步监督的。代理必须保持不被阻塞。做出合理的决定，继续推进，事后由人类纠偏。由于代码改动是可逆且可审查的，错误决定的代价通常小于阻塞。

- 先推进，再呈现。完成工作，展示结果。不要问"我应该做 X 吗？"直接做 X，并说明原因。
- 让系统具备自愈能力。发现问题时，记录下来，并在下一轮修复。
- 不可逆操作（强制推送、删除生产数据、发送外部消息）仍然需要确认。
- 可逆操作（编写代码、编辑笔记、拆分任务）应当继续推进，不得阻塞。
- 产品方向由人类决定。执行过程不应被阻塞。
